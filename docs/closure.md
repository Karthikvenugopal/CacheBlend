# Research closure

**Closed at the user's request. Internal learning work only; do not use in resumes or outreach.** Preserve the code and evidence without presenting a successful repair method.

- **Validated mechanisms:** full recomputation, exact-prefix cache reuse, independent cache ownership and position/mask handling within the tested scope. The fixed-position first-layer attention-output update matched direct recomputation; it is not a deep-cache repair. Native Qwen3 repair endpoints passed. CPU/MPS float32 numerical checks and the retained native MPS/BF16 discrepancy are documented. The delta selector remains rejected.
- **Reproduced failures and limitations:** all 18 restricted choices matched on six selected Qwen3 pairs. Generated decisions showed four paired reuse errors under the intended labels, but restricted preference is not answer utility. Two CPU–MPS comparisons failed tolerance. The later input audit found noncanonical old padding for airline and bank's edited amount `3  0 USD`, not `30 USD`; bank supports qualified intended-label conclusions. These whole-prompt cache interventions are not equivalent to ordinary retokenized document edits or fresh-question reuse. TinyLlama factual efficacy remained inconclusive.
- **Negative repair result:** none of 399 frozen region choices recovered the full answer at 16/32 extra tokens. Local repair failed too; full-suffix controls recovered. Some KL improvements did not change answers. This rejects useful recovery within that operator/family/budget range, not every possible repair method. No practical speedup or novelty was established.
- **Untested questions:** well-formed held-out document edits, generalization, fresh-question effects, other budgets/region geometries/operators/layer schedules, repeated or length-changing edits, and practical end-to-end benefit. These are uncertainties, not an authorized research agenda.
