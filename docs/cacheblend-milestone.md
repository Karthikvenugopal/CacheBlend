# First CacheBlend milestone

Completed on the cached Qwen3-1.7B revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`, MPS float32/eager. Independent document and instruction chunk caches are composed with native-coefficient RoPE position correction. Every method receives identical assembled token IDs and computes the whole question suffix fresh. The custom full and naive paths match native full and native composed-cache suffix execution, including all K/V tensors; cache ownership and native replay checks pass.

The checks cover both fixed 4x128 and 8x128 pilot configurations. First-layer K/V and first-prefix next-token logits pass atol=rtol=2e-4, as does each chunk/layer correction against direct native RoPE of the captured pre-RoPE key. Five deep first-prefix V tensor comparisons still fail that tolerance between native executions with different attention shapes; those tensors are not claimed numerically equivalent. The initial offset-only rotation failed and is preserved separately. The gate was refined after diagnosis, with unchanged tolerance.
